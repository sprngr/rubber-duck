# duck-debug

**Tier:** default
**Group:** Analysis

Socratic debugging with two explicit modes: debug mode (root-cause questioning) and trace mode (read-only evidence for defs/refs/callers/tests/imports). Use when: "debug this", "why is X broken", "trace this failure", "where is this used", "map callers".
