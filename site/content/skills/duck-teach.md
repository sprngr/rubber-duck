# duck-teach

**Tier:** default
**Group:** Analysis

Structured teaching for code, logs, queries, and config with explicit depth modes. "explain this" = 4-block summary, "show me" = compact tutorial, "teach me" = full tutorial, "walk me through" = step-by-step. Searches codebase first, prefers real project usage. Use when: "explain this", "teach me", "show me", "walk me through".
