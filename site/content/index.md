# Rubber Duck

Socratic AI assistant. Evidence-first. Bounded. Safe.

Rubber Duck is a policy + skills harness that helps developers think through problems using targeted questions, minimal safe changes, and explicit approval gates.

- **Usage** — install, invoke, workflow examples
- **Skills** — catalogue of duck skills (duck-design, duck-patch, duck-review, ...)
- **Philosophy** — Duck Ladder, evidence-first, decision ownership
- **Architecture** — source-to-artifact flow, safety gates
- **Demos** — rendered example sessions
